# 更新说明

> 适用版本：**v1.6.29**

## 新增功能

- **全局字体升级**：内置 MiSans 字体——四端观感一致、数字用等宽数字（评分/年份整齐不跳），字号与行距统一规整
- **页面过渡回归原版**：大图向下溶解进背景的过渡方式恢复 1.6.14 的自然观感（柔和长渐隐），修复近期版本过渡突兀的问题
- **继续观看卡更对位**：继续观看横卡改用剧集/电影的背景图满框展示（此前误用竖版海报裁切），双模式一致；「继续观看」栏移到「媒体库」上方
- **导航栏样式可选（设置 → 外观）**：玻璃水滴款（默认，选中水滴改超椭圆）与全新「流体液态款」——点中间＋号像水滴一样分裂出三个动作钮（Emby / 声网 / 设置），液滴拉丝飞出、收回时反序吸回——整体效果照搬参考设计（含配色），图标沿用应用自带（修复一些已知问题）；导航栏与顶栏按钮适当缩小更轻盈
- **TV 遥控可靠性（安卓 TV）**：画面卡住时控制条随时可唤出（不再依赖焦点）；遥控操作全面防闪退护栏；缓冲内存自适应（防内存吃紧被系统杀进程），卡住自动修复期间防误触
- **海报与卡片更清晰**：首页轮播/详情页海报满幅大图（画面不被底部渐隐遮挡）；轮播只用电影封面；媒体库封面、海报卡按显示大小取图（清晰度对齐 SenPlayer 卡档），Logo 艺术字加载提速
- **评分秒显、缓存与零配置**：评分行逐源渐进显示、结果本地缓存（重启后即时显示不重复获取）；IMDb / 烂番茄 / Metacritic 内置数据源免配置点亮（可选填 OMDb key 覆盖），优先用服务器刮削数据；设置页「测试评分数据源」一键自检
- **豆瓣 / Letterboxd 评分徽章**：评分行新增豆瓣与 Letterboxd 徽章（豆瓣走官方接口直取、免配置更稳；Letterboxd 免 key 自动抓取），数据不全的条目自动隐藏
- **首页轮播加高 + 简介 + 多平台评分**：轮播改为大图构图（约半屏高），底部信息块新增 2 行剧情简介与多平台评分徽章（IMDb / 烂番茄影评 / Letterboxd / Trakt / Metacritic / 豆瓣，品牌图标 + 分数；缺数据的平台自动隐藏）；详情页同样展示评分徽章与 2 行居中简介（三点省略号），简介胶囊贴右下角一键展开全部，评分行在简介下方；详情两行简介加长（第一行满宽、第二行延伸到「全部」胶囊为止）
- **媒体信息徽章**：播放页进度条上方居中显示画质徽章（如 [4K] [DV P5] [HEVC] [60.0 fps] [25.33G]），玻璃圆角胶囊（安卓 / Windows / 鸿蒙）
- **视频详细信息面板**：播放器底栏最右新增信息按钮，点按弹出可滚动面板（文件 / 显示 / 视频 / 音频分组卡片，逐条列出编码、帧率、分辨率、色域、亮度、声道等）
- **弹幕弹窗**：点击弹幕按钮打开弹窗，管理弹幕开关与动效、搜索剧集弹幕源并绑定（多服务器并行匹配，自动记住绑定，换集自动匹配）
- **播放器内解码 / 引擎切换**：控制栏新增解码模式胶囊（SW / HW / HW+ 循环切换）与播放引擎胶囊（MDK / MPV 面板选择），不用退出播放页（安卓 TV / 手机、Windows）
- **默认播放器**：设置 → 播放器 → 默认播放器可选引擎，每次进入播放器从默认引擎开始
- **Anime4K 画质增强**：实时超分 + 线条锐化，看番画面更清晰锐利（设置 → 播放器配置 → MPV 开启；调试面板可快捷开关，默认关闭）
- **播放调试面板重写**：可拖动的半透明浮层，实时显示 HDR / 杜比视界参数（输入色域与传输曲线、信号峰值、输出映射、DV Profile、渲染后端 DV 支持情况）
- **杜比视界画质改善**：DV 内容改用感知映射，高光细节不再丢失
- **关于页完善**：新增联系方式与开源组件信息

## 优化

- MPV 网速显示改为视频流加载速度（更贴近播放体验；MDK/Erika 仍为设备下载速度近似）
- 服务器配置密码框新增小眼睛显示/隐藏切换
- 安卓 TV 遥控操作全面对齐：焦点导航、面板操作与焦点动画更顺手（安卓 TV）
- 视频输出默认改为 SurfaceView 独立显示层，TV 全分辨率输出（可在设置改回）
- 首页横向海报栏自动回正更柔和自然
- TMDB 模式滑动更流畅（逐项重绘隔离 + 玻璃滚动降级）

## 修复一些已知问题

- 修复切换播放引擎时闪退、部分 HDR 视频播放丢帧（安卓）
- 修复 TV 播放页黑屏与遥控焦点丢失（安卓 TV）
- 修复 Windows 高缩放比例下界面错位
- 修复鸿蒙切换解码模式卡顿
