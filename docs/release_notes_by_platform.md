# 更新说明

> 适用版本：**v1.6.13**

## 新增功能

- **配置备份与还原**：设置 → 数据页可导出/导入服务器、声网、TMDB、弹幕、Trakt 等配置，换设备或重装后一键恢复
- **MPV 渲染器精简**：去掉「自动」档，只保留 gpu-next 与 gpu（兼容）
- **TV 引擎设置改为独立板块**：「播放器配置」页列出各引擎，点击进入单独设置页，遥控器操作更顺手（安卓 TV）
- **Windows 弹幕改为界面层绘制**：开关弹幕不再卡视频，HDR 视频下弹幕颜色正常，弹幕数量与行数对齐安卓
- **播放调试面板重写**：可拖动的半透明浮层，实时显示 HDR / 杜比视界参数（输入色域与传输曲线、输出映射、DV Profile、渲染后端 DV 支持情况），四端一致
- **杜比视界画质改善**：DV 内容改用感知映射，高光细节不再丢失

## 优化

- 弹幕行数与显示效果进一步对齐各端
- 跳过片头提示贴剧集 Logo 右侧，不再遮挡
- 鸿蒙安装兼容性放宽，平板等更多设备可安装
- 平板布局与手机保持一致（底部胶囊导航）
- 首页横向海报栏自动回正更柔和自然

## 修复一些已知问题

- 修复 TV 模式切换播放内核异常
- 修复播放器顶栏显示问题
- 修复滚动时偶发卡顿
