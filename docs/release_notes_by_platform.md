# Android 更新说明

> 适用版本：**v1.6.3**

## 设置页重做（1.6.1）

- **主页改为玻璃卡片网格**，六个分类一眼看全（新增「数据」分类）
- 每个子页按语义分成 3~4 组**玻璃卡片**
- 下拉选项改为玻璃底部面板
- **缓存管理迁到「数据」**（从「通用」移出）
- **TV 遥控器适配**：三引擎切换改为分段胶囊（左右键直接切）

**跳过片头/片尾不再跟着控件一起消失**：此前 5 秒不动、控件自动隐藏时，
跳过提示也一起没了；现在它有自己独立的显示倒计时。

**横向海报栏回正不再卡住当前栏**。

## 滚动手感打磨（1.5.99）

- **手机端上下滑动更顺**：此前页面各自写死了滚动参数，把全局的回弹设置
  覆盖掉了（等于回弹从未生效，滑到边界还是「硬撞墙」）。现在统一走全局
  配置，回弹真正生效
- **首页打开时从顶部开始**：此前会记住上次的滚动位置，重开应用直接落在
  半截；现在每次打开都从开头
- **切回首页自动回顶部**：从其它标签切回首页不再停在原处
- **横向海报栏自动回正**：横向滚动了某一条海报栏后，再去滚别的栏时，
  前一条会平滑滑回开头——不会整页到处是半截内容
- **桌面去掉细滚动条**：观感不佳，回归系统默认

## 滑动更流畅、动效更自然（1.5.98）

**滑动卡顿修复**：
- 页面不再因为「任何设置变化」就整页重建（此前改个无关设置都会让首页重绘）
- 列表项独立渲染，滚动时只移动图层不重绘内容
- 记住滚动位置，切走再回来不会跳回顶部
- **滚动时自动降低玻璃折射开销**，停下 120ms 后恢复——这是手机端卡顿的主因

**手感与动效**：
- 列表滑到边界有**回弹**（iOS 式），不再「硬撞墙」
- 页面切换改为**从右侧滑入**（此前是生硬的缩放）
- 卡片按下有**轻微缩放反馈**（此前点下去毫无回应）
- 列表首次加载时**逐项淡入**，不再「闪一下全出现」
- 海报点击后**飞入详情页**（共享元素动画）
- 加载时显示**骨架屏**（形状预告内容），比转圈更有「即将出来」的感觉
- 滚动时顶栏从透明**渐显为玻璃条**
- 首页轮播背景有**视差**（背景比前景慢半拍）
- 下拉刷新改为**玻璃质感**指示器

**无障碍**：系统开启「减少动画」时，所有装饰性动效自动关闭（仅保留加载进度这类必要反馈）。

## 资源图加载优化（1.5.92）

- **切到声网页面不再卡顿**：此前 4 张操作截图按原图分辨率同步解码，切换
  标签时会明显掉帧；现在按显示尺寸解码并提前预热
- **首页启动更快**：TMDB 流媒体平台 logo（7 张，其中 Disney+ 单张 65 KB）
  此前在**首屏同步解码**；现在按显示尺寸解码并提前预热
- **外观设置页图标**加载不再闪烁

## 播放内核统一为 MPV（1.5.91）

**手机端**：播放器不再显示引擎切换按钮，统一使用 MPV（原生 Surface + HDR 直出）。
设置 → 播放器配置只显示 MPV 一页（解码 / HDR / 渲染器选项仍可调）。

**TV 端**：保留 MDK / Erika / MPV 三引擎切换（底栏按钮），因为不同盒子的硬解
能力差异较大，需要按机型挑内核。

> 升级后若之前选过 MDK/Erika，会自动切到 MPV，无需手动改。

## 房间模式修复（1.5.91）

- **视频与资源面板之间的缝隙消失**：此前两者边缘各自取整，中间会露一条
  底光；现在面板从视频右缘无缝铺到屏幕右缘
- **点分享 / 退出房间点取消后，视频不再从头播放**：此前隐藏窗口会销毁
  视频画布，恢复时播放器重新初始化；现在改为透明隐藏，播放位置保持不变


## 播放路径改为手动控制

**你可能遇到的问题**：某些设备明明能正常播放，却自动变成了「纹理」模式，
画质和色彩不如从前，而且重启应用也不恢复。

**原因**：之前引入的自动回退判据太宽——mpv 日志里只要出现 `could not create`
这类通用短语（音频设备、字幕字体、某个解码 profile 都会打），就判定
「Surface 渲染失败」，然后**永久**把设置改成纹理。误判一次，这台设备就再也
回不到 Surface。

**现在**：所有相关开关都改为手动。

| 设置项 | 位置 | 取值 | 默认 |
|---|---|---|---|
| 视频路径 | 播放器配置 → MPV | Surface / 纹理 | Surface |
| 渲染器 | 播放器配置 → MPV | 自动 / gpu-next / gpu（兼容） | 自动 |
| 解码方式 | 播放器配置 → MPV | 智能 / 硬解 / 软解 | 硬解 |

**升级后会自动迁移**：如果你之前被自动改成了「纹理」，升级后会自动恢复成
「Surface」。这个迁移只执行一次——之后你手动选纹理，不会被再次覆盖。

**如果播放黑屏或花屏**：

1. 设置 → 播放器配置 → MPV → 渲染器 → 改成「gpu（兼容）」
2. 仍然不行 → 视频路径改成「纹理」

# Windows 更新说明

> 适用版本：**v1.6.3**

## Windows 自动下一集 + 跳过提示位置（1.6.3）

- **自动下一集终于生效**：此前 Windows 播完一集就停住。根因是播放器
  被设为「播完停在最后一帧」，这个模式会让它**不发出播放结束通知**。
  现在改为监听「已到结尾」状态（与安卓/鸿蒙同款做法）
- **跳过片头/片尾提示位置调整**：片头提示贴在进度条**左端上方**、
  片尾提示贴在**右端上方**，不再遮挡进度条；样式改为圆角矩形
- 提示仍然有自己的显示倒计时，不跟随控制条一起隐藏

## Windows 播放三处修复（1.6.2）

- **点「继续观看」不再黑屏**：上一版改续播位置的方式用错了接口，导致
  加载命令失败、画面全黑。现已改为「文件就绪后再跳转」，稳定可靠
- **跳过片头/片尾提示移到底栏居中**，仍然不跟随其他控件隐藏
- **自动下一集生效**：此前 Windows 播完一集就停住（安卓正常），
  因为 Qt 播放窗从未通知「已播完」。现在补齐这条链路

## 设置页重做 + 续播修复（1.6.1）

**设置页全新外观**：
- 主页改为**玻璃卡片网格**，六个分类一眼看全（新增「数据」分类）
- 每个子页按语义分成 3~4 组**玻璃卡片**，长列表不再一滚到底
- 下拉选项改为玻璃底部面板
- **TV 遥控器适配**：三引擎切换改为分段胶囊（左右键直接切），
  分组卡片焦点不逃逸

**缓存管理迁到「数据」**：从「通用」移出，独立成一页。

**Windows 续播从头播修复**：此前点「继续观看」会从第 0 秒开始。
根因是加载媒体后立刻跳转，但那时文件还没就绪，跳转被丢弃。
现在把起点交给播放器内核在加载时精确跳转（与安卓/鸿蒙同款做法）。

**跳过片头/片尾不再跟着控件一起消失**：此前 5 秒不动、控件自动隐藏时，
跳过提示也一起没了。现在它有自己独立的显示倒计时。

**横向海报栏回正不再卡住当前栏**：此前前一条回正的同时会把用户正在滑的
那一条卡住；现在两者互不干扰。

## Windows 播放修复（1.6.0）

- **播放进度现在会上传到 Emby**：此前 Windows 播完一集，Emby 里没有任何
  观看记录和续播进度（Android / 鸿蒙正常）。根因是 Qt 接管播放时跳过了
  「会话开始上报」，且进度读取的是一台空闲引擎（恒为 0）
- **跳过片头 / 片尾现在能用了**：Qt 播放窗此前从不显示跳过提示（位置
  读取同样来自空闲引擎），点「播放/暂停」和拖进度也没反应
- 以上修复同样适用于「播放/暂停」「拖进度」等所有播放控制

## 滚动手感打磨（1.5.99）

- **首页打开时从顶部开始**，切回首页自动回顶部
- **横向海报栏自动回正**：滚了某条海报栏后去滚别的，前一条平滑滑回开头
- **上下滑动更顺**：页面不再各自覆盖全局滚动参数

## 单人播放恢复窗口按钮 + 侧边栏玻璃化（1.5.97）

**单人播放恢复原生窗口按钮**：上一版为房间模式去掉的系统标题栏，误伤了
单人播放——最小化/最大化/关闭三钮和左上角返回箭头都消失了。现在**仅房间

**侧边栏美化**：

## 侧边栏换新样式 + Esc 禁用（1.5.96）

**侧边栏改为垂直 Dock**：桌面宽窗口的左侧导航从「带横线分隔的列表」换成
macOS Dock 风格的独立玻璃方块——

- 收起时只占 72px，只有图标（鼠标悬停显示名称），主内容区更宽敞
- 展开时 200px，图标 + 文字并排
- 选中项放大并带主色发光，一眼能看出当前在哪一页
- 底部一个圆形按钮切换收起/展开

**Esc 键不再做任何动作**：此前按 Esc 可能弹出「退出房间」确认、或在单人
播放时直接关掉播放器窗口，容易误触。现在 Esc 完全无响应；退出请点窗口
关闭按钮（单人）或右侧面板窗的关闭按钮（房间，有确认框）。

## Windows 设置简化（1.5.95）

播放器配置里移除了两项对 Windows 没有实际意义、反而容易出问题的设置：

- **视频路径**：Windows 只有 Surface 可用（纹理路径会直接闪退），
  原先的下拉框等于摆了一个「点了就崩」的按钮。现已移除并固定为 Surface
- **使用 Qt 播放器窗口**：Qt 窗口是 Windows 上唯一完整的播放器
  （进度条 / 播放控制 / 音量 / 选集 / 音轨 / 字幕），关掉只剩没有控件的
  裸窗口。现已固定启用

升级后若旧配置里存过「纹理」或「关掉 Qt 窗口」，会自动纠正，无需手动处理。

## 房间两窗不再遮挡其他软件（1.5.94）

上一版把房间的两个窗口做成了「始终置顶」，会把你正在用的其他软件永久盖住
——这是理解偏差，已改正。

现在：**两窗保持同一层，但不置顶**。
- 点视频窗 → 面板一起跟到前面（两窗不会一前一后拆散）
- 点面板窗 → 视频窗也跟着到前面
- **切到别的软件 → 两窗一起被正常盖住**，不会挡住你的其他窗口
- 全屏是唯一例外（全屏时面板不跟随）

## 无响应（Application Hang）修复（1.5.93）

Windows 11 上「进房间」或「移动播放器窗口」时程序无响应、被系统强制关闭
（事件查看器 Application Hang 1002）。三个主线程阻塞点已全部移除：

- **日志不再同步写盘**：此前每条日志都在界面线程做一次「打开文件 + 写入 +
  强制刷盘」，拖动窗口时每秒几十条，累积后界面线程被堵死。现在改为内存
  缓冲 + 批量异步写盘
- **窗口查找不再遍历所有窗口**：此前按类名查找主窗口要枚举系统里全部顶层
  窗口（含其他软件），任一窗口卡住就会拖住本程序。现在改为按类名直接定位
- **窗口跟随不再自我触发**：两窗跟随存在回环（程序移动窗口 → 系统迟到事件
  → 被当成用户拖动 → 再移动），拖动时无限循环。现在加了目标去重与 16ms
  节流

  4K 屏也不会变成巨幕；之后仍可自由拖动缩放
- **两个窗口保持同层**：点其中一个，另一个会一起跟到前面，不会再出现
  「一个在前面、另一个在后面」。**不置顶**——切到别的软件时两窗一起被
  正常盖住，不会挡住你的其他窗口；全屏是唯一例外（全屏时面板不跟）

## 房间模式：双窗协作

**之前的状况**：开启 Qt 播放器后进房间，两个窗口同时出现——Qt 窗口只播视频
没有任何房间信息，Flutter 播放页是黑屏；房主的播放/暂停传不到观众，观众
的进度永远停在开头。

**现在**：两个窗口各司其职，**拖哪个另一个都跟着走**。

| 窗口 | 职责 |
|---|---|
| Qt 播放窗（左） | 视频、播放/暂停、进度、音量、字幕、音轨、弹幕、片头片尾标记 |
| Flutter 面板窗（右，约 380 宽） | 房间码 / 在线人数 / 角色徽章 / 资源列表 / 播报板 / 加资源 / 分享 |

**摆位与缩放**：

- **进房间即摆好**：还没选片播放时两窗就已经左右并排
- **双向跟随**：拖左边视频窗，右边面板窗跟着贴过去；拖右边面板窗，左边
  视频窗跟着缩放。拉伸任一窗，两窗始终等高
- **不堆叠**：面板窗最小宽 320、视频窗最小宽 480，拖到更窄会停住，
  不会互相压住
- **面板窗去掉最大化/最小化按钮**：房间模式下面板是播放器的附属面板，
  最大化会挤掉视频窗、最小化会让人以为房间没了。关闭与拖边缩放保留

## Qt 播放窗精简

- **去掉系统窗口按钮**（最小化 / 最大化 / 关闭）——退出统一走右侧面板窗
- **去掉左上角返回按钮**——同上
- **顶栏整条可拖动**，**四边四角都可拉伸**（无边框窗口自己补的热区）
- **去掉窗内资源面板**：房间资源只在右侧 Flutter 面板窗操作，不再重复
- **两个窗口都出现在任务栏**：播放器与面板各有独立图标，点哪个切到哪个

## 拖动与缩放（1.5.90 修复）

两个窗口现在是**真正互相跟随**，谁被拖动谁就是锚点：

- **拖视频窗** → 面板贴着它右侧平移、严格等高
- **拖面板窗** → 视频窗跟着平移、等高
- **拉伸任一窗的高度** → 两窗始终等高
- 面板高度可以自由调高或压矮（此前被卡在最大高度，只能变矮）
- 拖动过程中不再有"弹回原位"的现象

## 关窗退出（1.5.87 修复）

- **点面板窗的关闭按钮现在会正确弹出「退出房间」确认**
  （此前会直接关掉视频窗，房间悬空）
- 取消后视频继续播；确认后才关闭并回到详情页

## 房间解散与删除资源（1.5.88 修复）

- **房主解散房间时，观众的播放器窗口会自动关闭**并回到首页
  （此前会一直挂在桌面上）
- **删除正在播放的资源时，视频会真正停止**
  （此前画面会停在最后一帧继续播放）

## 关闭面板窗 = 退出房间

点右侧面板窗的关闭按钮不再直接退出，而是弹出确认：

| 你的身份 | 提示 |
|---|---|
| 房主 | 「解散房间 / 离开将解散当前房间，所有观众将被退出」 |
| 观众 | 「离开房间 / 确定离开当前房间吗？」 |

- **取消**：什么都不会发生，视频继续播、房间继续在
- **确认**：关闭视频窗、回到详情页（房主解散后观众会被退出）

单人播放（非房间）时关闭窗口仍和以前一样直接退出，不弹确认。

## 房间面板液态玻璃风格

右侧面板窗整体改成液态玻璃：

- 黑底 + 轻磨砂 + 微透（不刺眼，暗场景下也不发灰）
- 头部（资源 / 人数 / 角色 / 分享）、资源分组、每个集行、播报板
  都是独立玻璃卡片，带白色描边与轻投影
- 当前播放的集有紫色 2px 描边高亮
- 设置里关闭「液态玻璃」会自动降级为深色实底

## 资源分组展开动画

点分组标题（剧名 / 季）不再瞬间展开，改为 220ms 平滑过渡：

- 内容高度渐变 + 淡入
- 左侧箭头平滑旋转 90°（收起指向右、展开指向下）
- 连续快速点击也跟得上，不闪不跳

## 房间分享

房间模式下资源面板头部有**分享按钮**（仅房主）：弹出二维码 + 房间码，
可分享/保存二维码或复制房间码。分享弹窗打开期间 Qt 播放窗会自动让位，
不会被顶层窗口盖住。

- 房主的心跳与广播改读**真实播放引擎**——之前读的是一台从未起播的空闲
  引擎，位置恒为 0
- 房主的播放/暂停/拖动进度/切倍速会**立即广播**给观众
- 房主在面板里换集会正常下发新流给观众（此前被会话层截断，不广播）

## 播放器窗口带完整控件

**之前的状况**：点播放会弹出一个独立窗口，但**里面只有视频、没有任何控件**
——想暂停只能按空格，想调音量没地方调，想选集只能退回 Flutter 界面。

**现在**（对照 Flutter 播放页逐项还原）：

| 区域 | 内容 |
|---|---|
| 顶栏 | 返回 / 标题 / 网速 / 内核胶囊（MPV）/ 显示调节 / 解码 / 画面比例 |
| 底栏第一行 | 当前时间 + 进度条（可拖动）+ 总时长 |
| 底栏第二行 | 上一集 / 播放暂停 / 下一集 · 音量滑杆 + 数值 · 亮度滑杆 + 数值 · 弹幕 / 多版本 / 字幕 / 音轨 / 选集 / 倍速 / 全屏 |
| 面板 | 选集（集数+标题）/ 多版本（版本切换）/ 音轨 / 字幕（含关闭）/ 倍速（0.5x~3.0x）/ 解码（智能/硬解/软解）/ 显示调节（字幕大小/位置/延迟 + 弹幕速度/大小/透明度） |
| 视频区 | 左侧锁钮（锁定后隐藏控件，防误触）+ 左下角剧集 Logo（240×44） |
| 快捷键 | 空格暂停 / ←→ 快退快进 10 秒 / ↑↓ 音量 / F 全屏 / Esc 退出 |
| 自动隐藏 | 播放中 5 秒无操作自动隐藏控件，移动鼠标重新显示 |

**样式说明**（1.5.82 起）：播放器窗口的控件样式改用开源组件库
[EvolveUI](https://github.com/sudoevolve/EvolveUI)（MIT 协议）统一渲染，
图标为 Font Awesome——**布局与功能和 Flutter 播放页一致，观感更现代化**
（动效/悬停反馈由组件库提供）。亮度图标为黄色、滑杆带数值显示等
功能规格不变。

**开启方式**：

```
设置 → 播放器设置 → 播放器配置 → MPV
  → 打开「使用 Qt 播放器窗口」
```

**如果开启后还是看到旧窗口**（有标题栏但没有顶栏/底栏控件）：

1.5.76 有个 bug——单人点「开始播放」时 Qt 进程根本没启动，静默回退到了
旧窗口。1.5.77 已修复。请确认版本是 **1.5.77 或更高**。

**如果播放器窗口不能拖动/缩放**：同样是 1.5.76 的问题（无边框窗口没有
标题栏），1.5.77 已改为标准窗口。

**默认是关闭的**。这是新方案，还没有经过大规模真机验证。如果开启后遇到问题，
关掉这个开关就会回退到原来的窗口，不影响使用。

## HDR 默认值修复

**之前的状况**：设置页显示「视频路径 = Surface」，但实际播放走的是「纹理」
（SDR 色彩），**HDR 片源永远用不上 HDR 直出**。

**原因**：之前只改了设置页显示的那处逻辑，漏了实际播放判定的那处，两处长期
不一致。

**现在**：两处统一，新用户默认走 Surface + HDR 直出。

**怎么验证 HDR 生效**：

- HDR 片源的高光（阳光、灯光、火焰）**通透、有刺眼感** → HDR 直出成功
- 高光发灰、整体发闷 → 仍是 SDR
- 或者按 `Win+Shift+S` 截图：截图**明显过曝** → HDR 直出（屏幕亮度被压到
  截图范围）

## 播放器窗口可拖动缩放

窗口从「覆盖在 Flutter 上的浮层」改成**独立标准窗口**：

- 有标题栏，可拖动、缩放、最小化、最大化
- 关闭按钮或 ESC 退出播放
- 不再跟随 Flutter 窗口位置
