# 更新说明

> 适用版本：**v1.6.14**

## 新增功能

- **弹幕弹窗**：点击弹幕按钮打开弹窗，管理弹幕开关与动效、搜索剧集弹幕源并绑定（多服务器并行匹配，自动记住绑定，换集自动匹配）
- **播放器内解码 / 引擎切换**：控制栏新增解码模式胶囊（SW / HW / HW+ 循环切换）与播放引擎胶囊（MDK / MPV 面板选择），不用退出播放页（安卓 TV / 手机、Windows）
- **默认播放器**：设置 → 播放器 → 默认播放器可选引擎，每次进入播放器从默认引擎开始
- **Anime4K 画质增强**：实时超分 + 线条锐化，看番画面更清晰锐利（设置 → 播放器配置 → MPV 开启；调试面板可快捷开关，默认关闭）
- **播放调试面板重写**：可拖动的半透明浮层，实时显示 HDR / 杜比视界参数（输入色域与传输曲线、信号峰值、输出映射、DV Profile、渲染后端 DV 支持情况）
- **杜比视界画质改善**：DV 内容改用感知映射，高光细节不再丢失
- **关于页完善**：新增联系方式与开源组件信息

## 优化

- 安卓 TV 遥控操作全面对齐：焦点导航、面板操作与焦点动画更顺手（安卓 TV）
- 视频输出默认改为 SurfaceView 独立显示层，TV 全分辨率输出（可在设置改回）
- 首页横向海报栏自动回正更柔和自然

## 修复一些已知问题

- 修复切换播放引擎时闪退、部分 HDR 视频播放丢帧（安卓）
- 修复 TV 播放页黑屏与遥控焦点丢失（安卓 TV）
- 修复 Windows 高缩放比例下界面错位
- 修复鸿蒙切换解码模式卡顿
